# Data Types

The Wendoo language supports several data types:

## Number

Numeric values used for counting, measuring, and arithmetic.
Number literals can be typed directly (e.g. `42`, `3.14`).

## Boolean

True or false values used in conditions and logic.
Boolean tiles represent yes/no states.

## String

Text values used for display and identification.

## Other Types

These are the basic data types common to all Wendoo-enabled experiences. Applications
may define their own data types in addition.

A variable of any type can also hold nothing, which is no value at all; `concept:nothing` has
the details.
